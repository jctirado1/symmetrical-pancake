# assets

Put the files from your **GAMEPRO** download in here (models, textures, sounds).
Godot imports anything placed in this folder automatically.

Suggested layout:

- `assets/models/`   – `.glb`, `.gltf`, `.fbx`, `.obj` 3D models
- `assets/textures/` – `.png`, `.jpg` images
- `assets/audio/`    – `.ogg`, `.wav`, `.mp3` sounds
